## ▶️ 실행 방법

```bash
# 1. 저장소 클론
git clone https://github.com/Chaewon-Park-STUDY/Pleos-Car-App-Contest.git
cd Pleos-Car-App-Contest

# 2. 빌드
./gradlew assembleRelease
```

또는 `apk/` 폴더의 APK를 Pleos Playground 테스트 환경에 설치해 실행합니다.
