# 시연 영상 대본 (약 2분 15초)

> 앱 이름은 확정 후 `PaceNote (페이스노트)` 자리만 바꾸면 됩니다.
> 자막은 편집 프로그램(예: CapCut, 클립챔프)으로 넣거나, 내레이션으로 읽어도 됩니다.

## 녹화 준비 (5분)
1. 에뮬레이터 실행 → 앱 실행 → **설정 → 기록 모두 지우기**, 운전자가 이미 있으면 **운전자 바꾸기**로 첫 화면
   - 완전히 처음 상태로 찍으려면: 에뮬레이터에서 앱 길게 눌러 **앱 정보 → 저장공간 → 데이터 삭제**
2. 에뮬레이터 **소리 켜기** (음성 안내가 영상에 들어가야 함)
3. 녹화 방법 (둘 중 하나)
   - **에뮬레이터 자체 녹화**: 에뮬레이터 옆 `⋯`(Extended controls) → **Record and playback** → Start recording → 끝나면 Stop → webm/gif 저장
   - **Windows 녹화**: 에뮬레이터 창 클릭 후 `Win + Alt + R` (시작/중지) → `동영상\캡처` 폴더에 저장
4. 한 번 리허설 후 본 녹화. 실수하면 해당 장면만 다시 찍어 이어 붙여도 됩니다.
