# 아이디어 노트

> 현대자동차그룹 차량용 앱 개발 공모전 기획 논의 정리 (2026-10-31 기준)

---

## 1. 대회가 원하는 것

- **주제**: 차량 데이터, 차량 기능, 이동 상황을 활용해 운전자·탑승자에게 새로운 경험을 주는 차량용 앱
- **예시 분야**: 모빌리티 & 라이프 편의(주문·픽업·주차·**충전**), 인카 엔터테인먼트, 스마트 드라이빙 & 안전, 패밀리 & 동승자 케어, 그 밖의 주제
- **대회 목적**: Pleos 앱마켓에 올릴 앱 확보 + 외부 개발자 생태계 확대. 우수작은 실제 출시 검토
- **개발 환경**: Android API 28+, Gradle 8.0+, Java/Kotlin
- **Pleos Connect SDK**: Vehicle(차량 상태), FusedLocation(위치), NaviHelper(길 안내), TextToSpeech, SpeechToText

### 1차 서류심사 기준 (배점 비공개)

| 항목 | 내용 |
| --- | --- |
| 차량특화성 | 모바일 대비 차량 환경만의 가치, 주행·정차 맥락 및 차량 기능과 결합 |
| 창의성 | 독창성, 명확한 Pain Point & Needs와 해결 방식 |
| 기술 활용성 | Pleos SDK·API를 핵심 기능에 활용 |
| 사업성 | 타깃 고객, 예상 MAU, Retention, 서비스 확대 계획 |

가산점: 시연 영상, GitHub(소스 + APK) 제출 시 단계별 부여

### 우선순위 해석 (공식 순위 아님)

1. **차량특화성**: 폰으로도 되는 앱이면 Pleos에 올릴 이유가 없음
2. **기술 활용성**: SDK가 없으면 앱이 성립하지 않는 구조여야 함
3. **실현 가능성 / 사업성**: 2차 PT 전까지 실제 동작하는 앱 필요
4. **창의성**

## 2. 출발점: 운전자로서 느낀 불편

- 전기차 상태(배터리 등)를 차 안에서 확인할 수 있는 시스템이 잘 없음
- 연료 게이지가 **칸 단위**라서
  - 실제로 얼마 남았는지 모름
  - 칸이 줄어드는 속도가 일정하지 않아 언제 확 떨어질지 예측이 안 됨
  - 경고등(마지막 한 칸 ≈ 2만 원어치)은 거의 바닥일 때만 켜짐
- 테슬라처럼 남은 양을 **% 수치**로 보고 싶음

---

## 3. 아이디어 방향 (후보)

**남은 연료·배터리를 수치로 보여주고, 언제·어디서 채울지 판단해 주는 차량용 앱** (연료차 + 전기차 통합)

> ⚠️ 현대차는 이미 계기판에 주행가능거리(km)를, 전기차는 배터리 %를 보여줌.
> → "% 표시"는 기본 화면으로만 두고, 아래 기능으로 차별화해야 함.

| # | 기능 | 심사 기준 연결 | 사용 SDK |
| --- | --- | --- | --- |
| 0 | 남은 연료·배터리 **%와 리터** 수치 표시 (기본 화면) | - | Vehicle |
| 1 | **"언제 떨어지나" 예측**: 최근 주행 패턴(연비·속도)으로 "약 ○○km, ○○분 뒤 경고등" + 불확실성 구간 | 창의성 (통계 모델링 강점) | Vehicle |
| 2 | **목적지 기반 판단**: 내비 경로와 남은 연료·배터리 비교 → "충분 / 가는 길에 주유·충전 필요" | 기술 활용성 | NaviHelper, FusedLocation |
| 3 | **주행 중 음성 안내**: "○km 앞 주유소가 가장 저렴해요" | 차량특화성 | TextToSpeech, SpeechToText |
| 4 | **금액 환산**: "남은 연료 ≈ 2만 원어치" | 창의성 | Vehicle (+ 유가 데이터) |

- 주행 중에는 음성 위주, 정차 중에만 상세 화면 → 주행/정차 맥락 활용
- 연료차·전기차 통합 → 타깃 확대(사업성)

## 4. 확인 필요 (리스크)

- [ ] Pleos Vehicle SDK가 외부 앱에 열어주는 데이터 확인 ([API 참조](https://document.pleos.ai/en/api-reference/connect-sdk-pleos/Vehicle/intro))
  - Android Automotive 표준 후보: `FUEL_LEVEL`, `INFO_FUEL_CAPACITY`, `RANGE_REMAINING`, `EV_BATTERY_LEVEL`
  - 참고: 클라우드용 Pleos Vehicle Data API는 SoC·충전 상태·주행가능거리는 제공, **SoH·배터리 온도·전비는 미제공**
- [ ] 연비/전비 추정에 필요한 값(속도, 주행거리 등)을 읽을 수 있는지

- [ ] 온라인 설명회(10/28) 자료 확인
